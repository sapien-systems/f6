# Physix — symboliskt metaspråk

**Syfte:** Ge vilken AI som helst ett kompakt, formellt system för att klassificera varje ord, objekt eller koncept i flera lager samtidigt.

## 1. Kärnformer (Shape)

| Symbol | Kod | Betydelse |
|--------|-----|---------|
| ○      | O   | Ren möjlighet, dröm, självmodell |
| △      | ^   | Information, data, påstående, kunskap |
| □      | #   | Rumtid / naturlig resurs / fysik (alltid underförstådd) |
| ⬠      | 5   | Mänskligt verktyg, kod, konstruerat |
| ⬡      | 6   | Koncentrerad farlig kraft / kärnkraft |
| ⬢      | 7   | Bana, fri fall, lämnat gravitationen |

**Regel:** □ är alltid ambient. Explicit □-nästning endast om objektet *är* en naturlig resurs (sten, träd, asteroid).

## 2. Perception (valens)

| Symbol | Betydelse |
|--------|---------|
| 🔴     | Bad – negativ, skadlig, oönskad |
| 🔵     | Good – positiv, önskvärd |
| —      | Neutral (ingen färg) |

Färg läggs **endast** på tydligt positiva eller negativa ord.

## 3. Sanning (Truth)

| Symbol | Betydelse |
|--------|---------|
| ⚫     | TRUE / ja / bekräftat |
| ⚪     | FALSE / nej / negerat |

## 4. Kaosdimension (Chaos)

| Symbol | Betydelse |
|--------|---------|
| Α      | Ordnad, systematisk, prydlig |
| Δ      | Kaotisk, rörig, turbulent |
| Λ      | Solo, individuell, separat |

## 5. Mappningsregler

1. **Shape** ← ontologisk kategori för referenten  
2. **Perception** ← talarens avsikt eller konventionell valens  
3. **Truth** ← polaritet (bekräftelse vs negation)  
4. **Chaos** ← strukturell regelbundenhet  

**Nästning:** högre form ⊂ ⬠ om konstruerat  
**Förändring:** → (formtransformation över tid)  
**Multi:** taggar sammanfogas med ⊂ eller +

## 6. Exempel

```
sol          = ⬡ ⊂ □   — ⚫ Α
reaktor      = ⬡ ⊂ ⬠   — ⚫ Α
satellit     = ⬢ ⊂ ⬠   — ⚫ Α
robot        = ⬠       — ⚫ Α
människa     = □ → ⬠   — ⚫ Α
dröm         = ○       — ⚫ Λ
inte / nej   = △ 🔴 ⚪ Δ
ja / bra     = △ 🔵 ⚫ Α
desorden     = △ 🔴 ⚫ Δ
```

## 7. Användning

- Översätt vilket ord som helst i vilket språk som helst till Physix-tagg.  
- Använd nästning och → för att beskriva relationer och förändring.  
- Behåll □ som underförstådd bakgrund om inte objektet är naturligt.  
- Färga endast tydliga +/-.  
- ⚫ = ja/sant, ⚪ = nej/falskt.

**Physix är struktur, inte metafor.**
