# Logos

| File | What it is | Use |
|------|------------|-----|
| `sophios-logo.png` | The SophiOS logo: a white S-shaped swirl with a red and a blue circle. Transparent background | On **dark** backgrounds only (the swirl is white) |
| `sophios-logo-on-black.png` | The same logo on black, with padding | README banners, social previews, anywhere a ready-made image is needed |
| `anonymous-group-emblem.png` | The emblem of the anonymous group behind the project: an alien head above a stylized X, white on black | Credits and team pages (see [docs/team.md](../../docs/team.md)) |

All images are saved without embedded metadata. Please keep it that way: strip metadata from any image before adding it to the repo.
